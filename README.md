# WakeOnLan (Android)

Приложение-утилита: когда телефон подключается к домашней Wi-Fi сети после
отрыва дольше заданного времени («минимальный отрыв»), оно шлёт Wake-on-LAN
magic packet, и компьютер включается. Пока вы дома, короткие переподключения
Wi-Fi комп не будят. Геолокация не нужна — домашняя сеть определяется по
IP-подсети.

- Язык: Kotlin, UI: XML + Material 3, minSdk 26, targetSdk 36.
- Фоновая работа: foreground service (`specialUse`) + `ConnectivityManager.NetworkCallback`.
- «Дома»: подсеть телефона (главный признак, без разрешений) или SSID
  (запасной, требует разрешений на Android 13+).
- «Приход»: телефон в домашней сети и вне её был дольше «минимального отрыва»
  (по умолчанию 20 минут). Время последнего посещения хранится постоянно.
- Пакет шлётся 4 раза с интервалом 500 мс — и на направленный broadcast-адрес
  сети, и на 255.255.255.255.
- Magic packet адресован MAC-адресу конкретной сетевой карты: другие компьютеры
  и устройства в сети не затрагиваются.

## Сборка

```bash
gradlew.bat assembleDebug
```

Готовый APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Настройка на ПК (обязательно)

1. **BIOS/UEFI**: включить «Wake on LAN» / «Power On by PCI-E Device»,
   **отключить ErP/EuP** (без этого пробуждение из полного выключения не работает).
2. **Windows → Диспетчер устройств** → сетевая карта → Свойства:
   - вкладка «Управление электропитанием»: ✅ «Разрешить этому устройству
     выводить компьютер из ждущего режима» и ✅ «Разрешить вывод по пакету magic packet»;
   - вкладка «Дополнительно»: `Wake on Magic Packet` = `Enabled`.
3. **Отключить быстрый запуск**: Панель управления → Электропитание →
   Действия кнопок питания (гибридное выключение часто ломает WOL из S5).
4. ПК должен быть подключён к роутеру **кабелем** (пробуждение по Wi-Fi-карте
   из выключенного состояния обычно не работает).

## Использование

1. Установить APK, открыть приложение.
2. Вписать MAC-адрес ПК (`ipconfig /all` → «Физический адрес» у Ethernet-адаптера).
3. Дома нажать «Определить» — подставится подсеть (например, `192.168.0`).
   SSID можно не трогать — он запасной признак.
4. «Минимальный отрыв» — сколько минут телефон должен быть вне домашней сети,
   чтобы подключение считалось приходом (по умолчанию 20).
5. Включить тумблер «Следить за сетью» — появится тихое уведомление.
6. Тест: выключить ПК, выключить/включить Wi-Fi, дождаться подключения —
   в первые 20 минут после выключения Wi-Fi комп не включится (отрыв мал),
   позже — включится. Для мгновенной проверки есть кнопка «Отправить сейчас».

## Диагностика

Логи сервиса: `adb logcat -s WolService`.

## Если SSID не определяется (запасной признак)

- Android 13+: нужны разрешения «Устройства рядом» (NEARBY_WIFI_DEVICES)
  **и** «Геоданные». Кнопка «Текущая» сама открывает диалог.
- **Samsung / One UI**: SSID отдаётся только при включённой геолокации в системе.
- SSID всегда можно вписать вручную. Для основной работы (по подсети) он не нужен.
